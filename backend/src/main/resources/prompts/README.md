# AI 提示词模板

按 02 文档 §4.3，本目录存放 `ai` 模块使用的提示词，一套一类：

| 文件（规划） | 用途 |
|---|---|
| `short-answer-grade.md` | 简答批改（0~10 分，≥6 通过） |
| `interview-question.md` | 面试出题（题库抽取为主，AI 补生成） |
| `interview-grade.md` | 面试逐题评分与评语 |
| `interview-report.md` | 总体评价、能力雷达、补强建议 |

约定：
- 模板只放文本，变量用 `{{占位符}}`，由 `ai` 模块注入，不在 Java 里拼长字符串。
- 要求模型输出结构化结果（JSON），解析失败走降级逻辑而非静默失败（风险 R1）。
- 修改模板等同于改业务行为，需同步更新 02 文档 2.3 节说明。
